<task type="auto">
  <name>Task 1: Build ISOLATED world BridgeClient, Speed Engine, and Dynamic Quality Engine in `content.js`</name>
  <files>youtube-quick-controls/content.js</files>
  <action>
Architect `youtube-quick-controls/content.js` cleanly with modular internal classes/factories:
1. `BridgeClient`: Origin/source-verified `window.postMessage` RPC client speaking `YQC_BRIDGE` to `page-bridge.js` (`ping`, `getState`, `setQuality`, `setRate`, and `YQC_EVENT_PLAYER_STATE` / `YQC_EVENT_RATE_CHANGE` subscriptions) with request timeouts and pending-request cleanup.
2. `SettingsStore`: Async `chrome.storage.sync` (`local` fallback) loader + live `chrome.storage.onChanged` subscription.
3. **Playback Speed Engine**:
   - Supports all required presets `[0.25, 0.5, 0.75, 1.0, 1.25, 1.5, 1.75, 2.0, 2.25, 2.5, 3.0]` PLUS merges any additional custom rates exposed by `preferredRates` from YouTube (`getAvailablePlaybackRates()`) or the video's current `video.playbackRate`, plus an inline Custom speed entry row (`0.1x`–`16.0x`).
   - Applying speed mutates `video.playbackRate = rate` directly without calling `.pause()`, `.load()`, or `.currentTime = ...`.
   - Subscribes to `ratechange` on the active `<video>` with `isInternalRateChange` guard so keyboard shortcuts (`Shift+>`, `Shift+<`) and native menu adjustments sync pill & menu state without infinite loops.
4. **Dynamic Quality Engine**:
   - Queries `BridgeClient.getState()` cleanly with retry backoff if video metadata/manifest is still loading (`options.length === 0` or `isLoading`).
   - Populates ONLY the resolutions returned by the player (`144p`–`2160p (4K)` + `Auto` when `autoAvailable`).
   - Tracks `appliedQualityState` vs `pendingTargetQuality`:
     - Shows subtle loading indicator (`aria-busy="true"`) while `SET_QUALITY` verifies with the player.
     - Never updates pill label/checkmark to requested quality until confirmed (`result.applied === true`).
     - If `result.applied === false`, keeps previous visible quality selected, opens a non-color-only subtle error tooltip (`⚠ ...`), and falls back gracefully to the player's actual active state.
5. **Watch-Page Anchor & Accessible Dropdown Pill Component**:
   - Discovers watch-page Like element (`segmented-like-dislike-button-view-model`, `ytd-segmented-like-dislike-button-renderer`, `like-button-view-model`, `button[aria-label*="like" i]`) inside `ytd-watch-metadata #actions` / `#above-the-fold`.
   - Mounts `<div id="yqc-controls-host" class="yqc-root" data-yqc-mode="watch">` directly above the native actions bar (`#actions-inner` / `#actions`) aligned horizontally with the Like button's left edge (`margin-inline-start`), adding a vertical stack class on the container without touching YouTube's native buttons.
   - Stops pointer/click/keydown propagation from reaching YouTube's player hotkeys; closes dropdowns on outside click, `Escape` (returning focus to trigger), or sibling menu open.
   - Exposes internal test/inspection hook safely when non-conflicting (`globalThis.__YQC_CONTROLLER__`).
  </action>
