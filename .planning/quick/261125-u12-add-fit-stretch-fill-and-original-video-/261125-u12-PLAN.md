# Quick Plan: Video Display Controls (Fit, Stretch, Fill, Original)

## Objective
Add a compact row of four video display mode buttons (**Fit**, **Stretch**, **Fill**, **Original**) above the existing control rows (which sit above YouTube's Like / player controls) across normal watch, fullscreen, and Shorts views. Each button dynamically updates video scaling and aspect ratio immediately on click with a clear active-state indicator (`aria-pressed="true"`), without interfering with existing YouTube controls, speed/quality pills, or playback.

## Implementation Steps
1. **Controller & Display Row ([`youtube-quick-controls/content.js`](../../../youtube-quick-controls/content.js)):**
   - Define `DISPLAY_MODES` (`fit`, `stretch`, `fill`, `original`) and `displayMode` state (defaulting to `'original'`).
   - Mount `#yqc-display-row` (`role="group"`, `aria-label="Video display"`) above `#yqc-speed-row` and `#yqc-quality-row` inside `#yqc-controls-host`.
   - Implement `renderDisplayRow()`, `applyDisplayMode()`, `applyVideoDisplayElement()`, and `clearVideoDisplayOverrides()`, updating `<video>` attributes immediately on click, preserving selection across Watch <-> Fullscreen on the same video, resetting cleanly on new video navigation, and cleaning up on unmount/destroy.
   - Generalize `installToolbarKeyboardFallback` `ArrowUp`/`ArrowDown` navigation across all `.yqc-row` groups.
2. **Video Scaling & Active Styling ([`youtube-quick-controls/styles.css`](../../../youtube-quick-controls/styles.css)):**
   - Style `video.yqc-video-display[data-yqc-display='fit'|'stretch'|'fill']` with `width: 100% !important; height: 100% !important; inset: 0 !important; transform: none !important;` and `object-fit: contain | fill | cover` respectively, plus `.html5-video-container:has(> video.yqc-video-display[data-yqc-display])` sizing so YouTube's dynamic inline styles do not override active scaling while `'original'` leaves native YouTube styling untouched.
3. **Tests & Documentation:**
   - Add unit tests in `tests/unit-manifest-bridge.test.mjs` and real Chrome CDP E2E tests in `tests/e2e-chrome-dom.test.mjs` covering placement above existing controls, instant mode switching (`fit` / `stretch` / `fill` / `original`), computed `object-fit` verification, fullscreen persistence, and zero player interference; update `youtube-quick-controls/README.md` and `README.md`.
