# Quick Plan: Single-Row Control Groups (`261125-ua6`)

## Objective
Ensure each control group (**Video display**, **Playback speed**, and **Video quality**) strictly occupies a single horizontal row without wrapping onto multiple lines in Watch, Fullscreen, and Shorts modes.

## Implementation Steps
1. **Single-Row CSS & Fullscreen Sizing ([`youtube-quick-controls/styles.css`](../../../youtube-quick-controls/styles.css)):**
   - Replace `flex-wrap: wrap` with `flex-wrap: nowrap`, `overflow-x: auto`, `scrollbar-width: none`, and `scroll-snap-type: x proximity` on `.yqc-row`, with `flex: 0 0 auto` on `.yqc-chip` and compact `gap: 3px` / `padding-inline: 6px` so all pills fit on one line without shrinking below `24×24` CSS px.
   - Set `inline-size: max-content; max-inline-size: calc(100% - 16px);` on fullscreen `.yqc-root` overlays so the container expands leftward above the Like button instead of wrapping at the right edge of `#movie_player`.
2. **Watch Alignment Guard ([`youtube-quick-controls/content.js`](../../../youtube-quick-controls/content.js)):**
   - Reset `marginInlineStart` to `'0px'` before measuring `hostWidth` when `parentRect.width <= hostWidth` so narrow watch containers do not push the toolbar off-edge.
3. **Verification ([`tests/unit-manifest-bridge.test.mjs`](../../../tests/unit-manifest-bridge.test.mjs), [`tests/e2e-chrome-dom.test.mjs`](../../../tests/e2e-chrome-dom.test.mjs)):**
   - Assert `.yqc-row` uses `flex-wrap: nowrap` and verify in real Chrome E2E that every button inside `#yqc-display-row`, `#yqc-speed-row`, and `#yqc-quality-row` shares a single horizontal row (`maxTop - minTop <= 2`) in both Watch and Fullscreen modes.
